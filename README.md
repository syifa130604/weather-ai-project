# AI-Based Weather Prediction

## Deskripsi Project

Project ini merupakan aplikasi prediksi cuaca berbasis Artificial Intelligence yang dibuat menggunakan Python dan Flask. Sistem mampu melakukan prediksi kondisi cuaca menggunakan beberapa algoritma machine learning dan deep learning.

Algoritma yang digunakan:

- Linear Regression
- Artificial Neural Network (ANN)
- Long Short-Term Memory (LSTM)
- Backpropagation Neural Network
- K-Means Clustering

Aplikasi web ini memiliki fitur:
- prediksi cuaca,
- visualisasi data,
- dashboard evaluasi model,
- dan perbandingan performa algoritma.

# Cara Menjalankan Project

## 1. Masuk ke folder app

```bash
cd app
```

## 2. Install library

```bash
pip install -r requirements.txt
```

## 3. Jalankan Flask

```bash
python app.py
```

## 4. Buka browser

```bash
http://127.0.0.1:5000
```
